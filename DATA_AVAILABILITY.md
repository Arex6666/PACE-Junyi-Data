Data Availability

The original Junyi Academy Online Learning Activity Dataset is publicly available from Junyi Academy Foundation through Kaggle (https://www.kaggle.com/datasets/junyiacademy/learning-activity-public-dataset-by-junyi-academy). The Junyi data materials shared for this study are available in the PACE-Junyi-Data repository, release v1.0.0 (https://github.com/Arex6666/PACE-Junyi-Data/releases/tag/v1.0.0), including a cleaned event subset for the 100 sampled learners, the 7,500 interaction seeds used to construct the analysis inputs, selected exercise and learner metadata, derived learner profiles and knowledge-point mappings, and accompanying variable definitions and coding schemes. The documentation identifies observed, inferred and sampled fields. The complete original dataset is available from the source provider rather than duplicated in the repository; the shared Junyi-derived data retain the source dataset's CC BY-NC-SA 4.0 license.
